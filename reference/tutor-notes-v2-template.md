# Topic title

Status: draft. Original teaching material; requires human content review.

Write six or seven connected paragraphs, roughly 400–600 tokens. Character count
divided by four is only an estimate. Do not pad a simple topic to meet a count.

1. Define the concept and the quantities it relates. State the intended scope.
2. Explain why the central rule works, including assumptions and domain limits.
3. Give the formulas in plain text and define every symbol and unit.
4. Explain a practical solving procedure and how to check the result.
5. Provide one worked numerical example with every intermediate value checked.
6. Describe common mistakes and how to avoid them without diagnosing a learner.
7. State connections to prerequisites and boundaries the notes do not cover.

Review the method, arithmetic, wording and answer uniqueness. Publication requires
a real reviewer, review date and SHA-256 of the exact file bytes. See
docs/tutor-v2.md. This template and all files in reference/tutor-notes-v2/ are
drafts and are never retrieved by the learner API.
